DeskFur - your desktop, a little furrier.

WINDOWS START - EXE INSTALLER
1. Quit any older DeskFur using the tray menu.
2. Double-click DeskFur-Setup-0.2.1.exe.
3. Setup installs everything, creates a desktop shortcut, and opens your pet.
4. Later, double-click DeskFur on your desktop. No commands are needed.

The installer contains the complete runtime. No separate download is required.
Windows 10/11 64-bit, current-user install, no administrator rights needed.
If using the older ZIP download instead: extract it and run Start-DeskFur.cmd.
That fallback downloads a verified runtime only on its first launch.

SHIMEJI BEHAVIOR: pets walk, sit, jump, climb screen edges and fall when dropped.
Right-click a pet for its menu. Controls start hidden; use Ctrl+Shift+P or the
small DeskFur button to open them. Disable Shimeji-style movement for classic
wandering. Pets climb screen edges, not other programs' window borders.

MY PET: drag, feed, pet, sleep, change expression, ask the time, and turn on Duo
mode. Ctrl+Shift+P or the tray menu restores hidden controls. Quiet mode mutes
sounds. Your primary pet can be customized; the extra companion is local.

SPRITES: import your PNG or JSON sprite pack. Try
%LOCALAPPDATA%\Programs\DeskFur\resources\sprite-examples\mochi\character.json. Use the grid controls to animate a sheet,
then export PNG + JSON for easy editing. See sprite-examples/EDITING-GUIDE.txt.

FRIENDS: Internet multiplayer needs a hosted relay. A public relay is NOT included
or running yet. One friend hosts the provided server once; both enter the same
wss:// address, then create/join using a private room code.

HOST ON RENDER (one-time setup by one friend)
Create a Node Web Service from https://github.com/walpbear/Testing
Root directory: desktop-pals/server
Build command: npm ci --omit=dev
Start command: npm start
Health check path: /health
Node version: 24
Review the hosting plan; free-plan availability and sleep limits may change.
When your URL is https://your-service.onrender.com, enter
wss://your-service.onrender.com in DeskFur. Share that address and your room code.
Full server source, Render configuration, and instructions are in server/.
You can also host it elsewhere with WebSocket/TLS support.

GAMES: choose a connected friend, challenge them to tic-tac-toe, RPS, or High Card.
The friend accepts before play. Shared dice support D4 through D100 and modifiers.
Dice also work offline. Messages are delivered while users are in the room.
